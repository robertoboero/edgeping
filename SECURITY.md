# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub's **Report a vulnerability** button, in the **Security** tab of this repository (https://github.com/robertoboero/edgeping/security). The report stays visible only to the maintainer and to you until a fix is published.

Include the version or commit, the macOS version, and the steps that reproduce the problem. Remove any project names, paths or log lines that identify you or your clients before sending.
